Build (any OS with Go 1.24+):
  GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-H windowsgui -s -w" -o "TLOU Mod Installer.exe" .
rsrc_windows_amd64.syso holds the icon + manifest (made with github.com/akavel/rsrc).
On other OSes "go run ." gives a small command-line test harness (cli_other.go).
